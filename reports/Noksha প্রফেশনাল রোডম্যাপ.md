# Noksha কে টপ-নচ করুন
Noksha v0.1.1 ইতিমধ্যে একক অফার ল্যান্ডিং → COD/ম্যানুয়াল bKash–Nagad → অর্ডার ডেস্ক → ফানেল অ্যানালিটিক্সের পূর্ণ লুপ চালায়, কিন্তু “প্রফেশনাল” বার এখন যেখানে থামে সেটা ডিজাইন ফ্রিডম নয়—**অ্যাট্রিবিউশন (Purchase + CAPI), কুরিয়ার/কনফার্ম অপস, ইনকমপ্লিট অর্ডার রিকভারি, SEO/থ্যাঙ্ক-ইউ, এবং সিকিউরিটি–কোয়ালিটি সিস্টেম**। বাংলাদেশের Facebook/TikTok COD সেলারের যাত্রা এখনো অ্যাড → মোবাইল সিঙ্গেল-অফার পেজ → ছোট COD ফর্ম → কল/মেসেঞ্জার কনফার্ম → Pathao/Steadfast/RedX → সেটেলমেন্ট; প্লাগিন জেতে যখন এই চেইন এক অর্ডার রেকর্ডে ধসে পড়ে, Google Sheet আর সিস্টেম অফ রেকর্ড থাকে না ([Sellsull LP গাইড](https://sellsull.com/blog/how-to-build-landing-page-facebook-ads-bangladesh); [Reoncore f-commerce](https://reoncorelabs.com/insights/f-commerce-order-management))। স্থানীয় বার (Bangla Landing Page, Eazifiy) ও গ্লোবাল বার (FunnelKit-গ্রেড পিক্সেল/CAPI) একসাথে পূরণ করলেই Noksha “লোকাল টয়” নয়, প্রফেশনাল টুল হিসেবে পড়ে। নিচের রোডম্যাপ Now / Next / Later ধাপে সেই ফাঁকগুলোকে অগ্রাধিকার দেয়—মাল্টি-প্রোডাক্ট স্টোর বা ERP নয়, **একক-অফার BD ল্যান্ডিং বিজনেসকে টপ নচ** করাই লক্ষ্য।

## বর্তমান বেসলাইন শক্ত, কিন্তু “সবকিছু” এখনো আংশিক
কোডবেস অডিট অনুযায়ী Noksha একটি বাংলাদেশ-ফার্স্ট ল্যান্ডিং + চেকআউট প্রোডাক্ট: React অ্যাডমিন SPA (`home`, `pages`/এডিটর, `orders`, `analytics`, `payments`, `brand`, `settings`), `noksha/v1` REST, নয়টি সেকশন টাইপ (`hero`, `benefits`, `product`, `countdown`, `reviews`, `faq`, `guarantee`, `html`, `order_form`), COD + ম্যানুয়াল bKash/Nagad + SSLCommerz গেটওয়ে, ফার্স্ট-পার্টি ফানেল অ্যানালিটিক্স, ব্র্যান্ড টোকেন, এবং থিম-স্ট্রিপড পাবলিক রেন্ডারার `/offer/{slug}/` ([noksha.php](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/noksha.php); [Controller.php](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/src/Rest/Controller.php); [Sanitizer.php](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/src/Pages/Sanitizer.php))। রিডিজাইনড এডিটর ইতিমধ্যে তিন-জোন ফোকাস ওয়ার্কস্পেস: বামে কনটেন্ট লিস্ট + ইন্সপেক্টর, মাঝে ডিভাইস-ফ্রেমড লাইভ প্রিভিউ iframe, `is-editing`-এ গ্লোবাল রেল লুকানো; কাস্টম HTML ২০k অক্ষর পর্যন্ত এবং `unfiltered_html` অনুযায়ী স্যানিটাইজেশন ([Editor.js](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/admin-src/screens/Editor.js))। চেকআউট নাম/ফোন বাধ্যতামূলক, BD geo, honeypot + রেট লিমিট, একই ফোনে ৭ দিনে ≥২ অর্ডারে রিস্ক ফ্ল্যাগ—এগুলো স্থানীয় COD নর্মের কাছাকাছি ([Checkout.php](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/src/Orders/Checkout.php); [Algomindz COD চেকআউট](https://algomindz.com/blog/cash-on-delivery-checkout-design-bangladesh/))।

যা **এখনো নেই বা আংশিক** (নোট অনুযায়ী উদ্ভাবন নয়): পিক্সেল সেটিংসে শুধু PageView—`Purchase`/`fbq`/`gtag` purchase ইভেন্ট নেই; কুরিয়ার API নেই (`shipped`/`delivered` ম্যানুয়াল); A/B, অ্যাব্যান্ডনড/ইনকমপ্লিট রিকভারি, মাল্টি-প্রোডাক্ট/ভ্যারিয়েন্ট, SEO/OG, কাস্টম ডোমেইন, ইমেইল/SMS, নন-অ্যাডমিন রোল, CSV/বাল্ক/প্যাকিং স্লিপ, অনবোর্ডিং উইজার্ড নেই; টেমপ্লেট মাত্র চারটি (`single`/`lead`/`festival`/`blank`); এডিটরে undo/redo/autosave/রিভিশন নেই ([current audit](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/research_notes/Noksha%20প্রফেশনাল%20রোডম্যাপ/current_noksha_audit.md))। SSLCommerz কোড আছে কিন্তু ডিফল্ট অফ এবং প্রোডাক্ট ভ্যালিডেশন ডিফার্ড; `available()` এখনো `ssl_ready` গেট করে না। এই বেসলাইন মানে: **ডিজাইন→পাবলিশ→চেকআউট→অর্ডার** লুপ আছে; **অ্যাড→অ্যাট্রিবিউশন→কনফার্ম→কুরিয়ার→সেটেলমেন্ট** লুপ এখনো অসম্পূর্ণ।

## প্রতিযোগী ও BD সেলার বার: পিক্সেল + অপস, শুধু সুন্দর পেজ নয়
গ্লোবাল “প্রফেশনাল” মানে অ্যাড ক্লিক → অফার → ছোট অর্ডার ফর্ম → পেমেন্ট/COD → থ্যাঙ্ক-ইউ/আপসেল, সাথে পিক্সেল, স্টেপ অ্যানালিটিক্স, টেমপ্লেট/A/B ([CartFlows](https://cartflows.com/wordpress-funnel-builder/); [FunnelKit](https://wordpress.org/plugins/funnel-builder/))। BD টুলগুলো আলাদা বার সেট করে: বাংলা টেমপ্লেট, ঢাকা ইনসাইড/আউটসাইড চার্জ, ফেক-অর্ডার কন্ট্রোল, ইনকমপ্লিট অর্ডার রিকভারি, bKash অগ্রিম, কুরিয়ার ফ্রড চেক—Bangla Landing Page ~৳৯৯/মাস ও LCP ~১.১s দাবি করে; Eazifiy Steadfast/Pathao/RedX ফ্রড, Meta CAPI, OTP, অসম্পূর্ণ অর্ডার কল লিস্ট দেয় ([Bangla Landing Page](https://banglalandingpage.com/); [Eazifiy](https://eazifiy.com/wordpress))। SaaS (ClickFunnels/systeme.io) স্ট্রাইপ/পেপ্যাল অপটিমাইজ করে; Noksha-এর ডিফেন্সিবল ডিফারেন্সিয়েটর হলো **হোস্ট/ডেটা মালিকানা, BDT প্যাকেজিং, বাংলা UX, COD+ওয়ালেট, কুরিয়ার/ফ্রড ওয়ার্কফ্লো**—কিন্তু FunnelKit-গ্রেড Meta CAPI + TikTok Purchase ছাড়া সেলাররা এটাকে “সস্তা লোকাল প্লাগিন” ভাববে ([FunnelKit CAPI ডক্স](https://funnelkit.com/docs/funnel-builder/global-settings/facebook-conversion-api/))।

BD অপস নন-নেগোশিয়েবল: কনফার্ম-সেন্ট্রিক স্ট্যাটাস (New → Confirmed → Packed → Booked → Delivered/Returned/Cancelled), বাল্ক কনফার্ম/কুরিয়ার/প্রিন্ট, Steadfast+Pathao+RedX create + ওয়েবহুক, বাংলা SMS, প্যাকিং স্লিপ/ইনভয়েস ([Reoncore](https://reoncorelabs.com/insights/f-commerce-order-management); [RedX API](https://redx.com.bd/developer-api/); [SteadFast Postman](https://documenter.getpostman.com/view/26211192/2sAYJ1mhpk))। Noksha-এর অর্ডার স্ট্যাটাস মডেল আংশিক মিল (pending → confirmed → shipped → delivered…), কিন্তু কুরিয়ার বুকিং, বাল্ক অ্যাকশন, CSV, SMS এখনো ম্যানুয়াল গ্যাপ। মার্কেটিং সাইডে Meta `Purchase`-এ **value + currency**, CAPI-তে hashed `ph` (ইমেইল প্রায়ই নেই), শেয়ারড `event_id`, TikTok `Purchase`, অর্ডারে UTM/fbclid—এগুলো Phase 1 মার্কেটিং মস্ট-হ্যাভ; কাউন্টডাউন/স্কার্সিটি/বাম্প পরের ধাপ ([Meta Pixel](https://developers.facebook.com/documentation/meta-pixel/reference); [Meta CAPI](https://developers.facebook.com/docs/marketing-api/conversions-api/using-the-api/))।

## ডিজাইন–UX–এডিটর: ফর্ম-ফার্স্ট থেকে ক্যানভাস-ফার্স্টে উন্নীত করুন
সেরা বিল্ডাররা কনটেন্ট/লেআউটে **ক্যানভাস-ফার্স্ট**, অ্যাডভান্সড অপশনে পাতলা সাইডবার—Gutenberg-এ ব্লক এরিয়া প্রাইমারি UI, Webflow-এ ইনলাইন এডিট + autosave + undo ([Gutenberg Block Design](https://developer.wordpress.org/block-editor/explanations/user-interface/block-design/); [Webflow canvas](https://help.webflow.com/hc/en-us/articles/33961319255059-Webflow-canvas-overview))। Noksha আজ **ফর্ম-ফার্স্ট ইন্সপেক্টর + সার্ভার-রেন্ডারড প্রিভিউ**—কাজ করে, কিন্তু “টপ নচ এডিটর” অনুভূতির জন্য Next ধাপে প্রিভিউতে ইনলাইন টেক্সট/ইমেজ এডিট, সিলেক্টেড সেকশনে কনটেক্সচুয়াল টুলবার (মুভ/ভ্যারিয়েন্ট/ডুপ্লিকেট), এবং debounced autosave + undo স্ট্যাক যোগ করা উচিত; Offer/Checkout/পেমেন্ট রুল আলাদা ট্যাবে রাখা (Shopify সেকশন মডেল: অর্ডারড টাইপড সেকশন, সীমিত ফ্রিফর্ম) ([Shopify sections](https://shopify.dev/docs/storefronts/themes/best-practices/templates-sections-blocks))। ১০২৪px-এ WP মেনু + রেল আগে Update বাটন কেটেছে; ফোকাস মোড ইতিমধ্যে মিটিগেট করে—CartFlows-স্টাইল ফুলস্ক্রিন এবং কন্টেইনার কোয়েরি আরও শক্ত করলে ল্যাপটপ অ্যাডমিন ক্রোম সহনীয় থাকে ([CartFlows Canvas Mode](https://cartflows.com/docs/cartflows-canvas-mode/))।

স্টোরফ্রন্ট কোয়ালিটি বার: এক অ্যাকশন, মেসেজ ম্যাচ, স্ক্যানেবল হায়ারার্কি, CTA-র পাশে ট্রাস্ট, মিনিমাম ফর্ম ফ্রিকশন; Baymard বলে required ও optional **দুটোই** মার্ক করতে হয় (ডেস্কটপে মাত্র ১৪% সাইট করে) ([Stripe LP practices](https://stripe.com/resources/more/ecommerce-landing-page-best-practices); [Baymard required/optional](https://baymard.com/research-articles/required-optional-form-fields))। Noksha টেমপ্লেটে হিরোতে অফার+মূল্য+COD স্পষ্টতা+এক CTA, প্রুফ স্ট্রিপ CTA-র আগে, বাংলা `lang` + লাইন-হাইট ~১.৬–১.৮, `letter-spacing: 0`, আসল বাংলা ফন্ট ওয়েট ([Bangla typography](https://abcltech.com/html-css/bangla-on-the-web.html))। সেকশন লাইব্রেরি বাড়ান (ট্রাস্ট বার, ভিডিও, স্টিকি CTA, রিটার্ন পলিসি স্নিপেট)—কিন্তু ফ্রি লেআউট বিল্ডারে না গিয়ে **ভ্যারিয়েন্ট + টোকেন** দিয়ে “কুৎসিত পেজ” আটকান; কাস্টম HTML এস্কেপ হ্যাচ রাখুন, তবে `wp_kses` অ্যালাউলিস্ট শক্ত করুন। আর্কিটেকচারে OfferDocument = মেটা + টোকেন + অর্ডারড সেকশন স্কিমা; একই রেন্ডার পাথ প্রিভিউ ও প্রোডাকশনে (ড্রিফট কমাতে); অজানা `type` লোডে বাতিল—এটাই মেইনটেইনেবল বিল্ডার প্যাটার্ন ([WP_Theme_JSON sanitize](https://developer.wordpress.org/reference/classes/wp_theme_json/sanitize/))।

WordPress মডেল: validate → sanitize → escape; REST-এ `permission_callback` + `current_user_can`—nonce একা অথরাইজেশন নয় ([WP Plugin Security](https://developer.wordpress.org/apis/security/); [REST endpoints](https://developer.wordpress.org/rest-api/extending-the-rest-api/adding-custom-endpoints/))। Noksha-এর সবচেয়ে বড় সিকিউরিটি সারফেস: **কাস্টম HTML**—`unfiltered_html` থাকলে আনএস্কেপড রেন্ডার; কমার্শিয়াল সেফটিতে টাইট `wp_kses` অ্যালাউলিস্ট + স্টোরড HTML পাথ রিভিউ P0 ([Sanitizer.php](file:///C:/Users/USER/Local%20Sites/test/app/public/wp-content/plugins/noksha/src/Pages/Sanitizer.php); [OWASP Webhooks](https://cheatsheetseries.owasp.org/cheatsheets/Webhook_Security_Cheat_Sheet.html))। পাবলিক চেকআউট ইতিমধ্যে nonce/honeypot/রেট লিমিট রাখে—ভালো; পরের ধাপে অর্ডার PII মাস্কড লগ, অবজেক্ট-লেভেল অথরাইজেশন (IDOR), SSL/কুরিয়ার ওয়েবহুকে HMAC/`hash_equals` + ইভেন্ট আইডি আইডেমপোটেন্সি + অ্যামাউন্ট রিকনসিল, এবং অডিট লগ (অ্যাক্টর/অ্যাকশন, র aw PII ছাড়া)। এখন সব অ্যাডমিন `manage_options`—প্রফেশনাল অপসে fulfillment রোল Next-এ আলাদা ক্যাপাবিলিটি চায়।

স্পিড: অফার পেজে CWV টার্গেট LCP ≤২.৫s, INP ≤২০০ms, CLS ≤০.১ (p75); হিরো ইমেজ ডাইমেনশন, কন্ডিশনাল অ্যাসেট (শুধু Noksha স্ক্রিন/অফার টেমপ্লেটে), চেকআউট/থ্যাঙ্ক-ইউ/রিটার্ন/ওয়েবহুক ক্যাশ এক্সক্লুশন ডকুমেন্ট—FunnelKit দেখায় ক্যাশ আপসেল/ডায়নামিক ফ্লো ভাঙে ([web.dev Vitals](https://web.dev/articles/vitals); [FunnelKit cache](https://funnelkit.com/docs/one-click-upsells/getting-started/why-upsells-are-not-triggering/))। এডিটর প্রিভিউ প্রতি এডিটে পূর্ণ-ডকুমেন্ট POST (৩৫০ms debounce)—INP ও রিকোয়েস্ট স্টর্ম কমাতে আরও স্মার্ট ডিবাউন্স/পারশিয়াল আপডেট P1। কোয়ালিটি বার: WPCS CI, PHPUnit (স্যানিটাইজার/চেকআউট/ওয়েবহুক/পারমিশন), bn/en i18n এক টেক্সট ডোমেইন (এখন SPA আলাদা `i18n.js`, PHP `.po` আলাদা—ডুয়াল সিস্টেম ঋণ), SemVer + changelog, ফিচার ফ্ল্যাগ গেটওয়েতে; Woo/FluentCRM/FunnelKit প্যাটার্নে অনবোর্ডিং উইজার্ড + “টেস্ট COD অর্ডার OK” + Tools (টেবিল ভেরিফাই, REST/ক্যাশ হেলথ) ([WP PHPUnit গাইড](https://developer.wordpress.org/news/2025/12/how-to-add-automated-unit-tests-to-your-wordpress-plugin/); [Woo setup wizard](https://woocommerce.com/document/woocommerce-setup-wizard/))।
